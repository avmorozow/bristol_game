# Проверка настоящей 3D-сцены

Дата: 5 сентября 2026. До публикации.

## Изменения

- Объёмные модели Three.js вместо плоских персонажей: отдельные части лица и тела, ручки и содержимое пакета, хвост, руки и ноги белки.
- Кража справа, слева и прыжком. Захват, испуг пакета, удержание, побег с пакетом; спасение возвращает пакет в центр.
- Сервер резервирует случайные исходы при старте. Клиент применяет тот же исход сразу на физическом тапе; транспорт подтверждает его позже, без повторной белки.
- Компактные панели оставляют сцену видимой. Убраны прогнозы, лишние пояснения и перекрывающий сцену прогресс в момент решения.
- Оригинальная тема 114 BPM: маримба, бас, щипковые аккорды, мягкая перкуссия, акценты напряжения.

## Автоматические проверки

Production-сборка и проверка TypeScript завершились успешно. Все 49 автоматических проверок прошли (44 игровых/API и 5 проверок рендера/компонентов). В проверке серверного HTML обновлено ожидание фонового изображения: теперь используется пустая сцена background.png вместо home.png с нарисованными персонажами.

44 проверки игры/API покрывают: баланс, однократные списания, суточная попытка, бустер, второй проигрыш, подарок, гостевые сессии, конкурентные запросы, повтор команд, очередь из 120 нажатий, звук и вибрация.

Новые проверки подтверждают неизменяемость плана при heartbeat и повторе команды, синхронное появление белки до ответа на тап, отсутствие поздней белки после трёх безопасных тапов, продолжение по тому же плану после спасения, миграцию существующей попытки без повторных списаний.

## Браузерный прогон

Локальный браузер: 390×844 и 320×568. Временный стенд удерживал ответы на игровые команды на 1500 мс, не изменяя серверные исходы. Стенд удалён перед сборкой.

| Сценарий | Результат |
| --- | --- |
| Три быстрых безопасных тапа, затем остановка | Счёт 5 сразу; после ответов и heartbeat белки нет |
| Четвёртый тап | Счёт 6 и страх; кража начинается до ответа сервера |
| Белка справа, слева, прыжком | Все варианты пройдены; пакет захвачен на сцене |
| Спасение | Одно списание 50; белка убегает, пакет по центру, обычное лицо |
| Вторая белка на восьмом тапе | Сумма обнуляется сразу; белка уносит пакет и покидает кадр |
| Отказ от спасения | Побег с пакетом, итог без начисления |
| 119 → 120 | Финальная панель появляется до ответа; награда 2350 и один подарок |
| Получение награды | Баланс 11452 → 13802, начисление один раз |
| Продолжить | Локальный переход; последние замеры 22,1 и 34,8 мс, без нового запроса |
| Изменение ширины | Canvas перерисовывается, пакет не исчезает |
| Музыка | AudioContext создаёт ноты после жеста; автоматические проверки выключения и паузы проходят |

В серии из 17 измеренных нажатий счётчик обновлялся за 9,9–54,4 мс. В последних сценах кража начиналась через 102–145 мс после физического тапа; ответ удерживался 1500 мс. Это измерения тестового браузера, не гарантия для каждого устройства.

Во время прогона исправлены замедленная анимация на программном рендере, подрезанный хвост, перекрытие прогресса и повтор входа белки при восстановлении уже проигранной попытки. Горячая перезагрузка разработки давала один промежуточный замер «Продолжить» 447,6 мс; после оптимизации последние замеры приведены выше.

## Границы проверки

В облачном браузере аппаратный WebGL отключён. Визуально проверен программный рендер тех же трёхмерных моделей; WebGL-ветка проверена типами и сборкой, но не глазами на физическом GPU. На устройствах без WebGL используются более простые материалы и неподвижные спокойные позы. Физическая вибрация и субъективное звучание на телефоне не проверялись.

Протокол исходов рассчитан на демонстрационные монеты: будущий план можно увидеть в инструментах разработчика. Сервер сохраняет контроль транзакций, но для реальных призов нужен другой защищённый протокол. При сетевом отказе остаётся явная проверка неподтверждённой операции; подтверждение финансовых действий не подменяется анимацией.
