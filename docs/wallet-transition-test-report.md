# Проверка анимации выигрыша и продолжения

Дата: 4 сентября 2026 года.

## Изменения

- После подтверждённого зачисления выигрыша десять монет летят к подсвеченному кошельку. Анимация не меняет баланс и не блокирует кнопки.
- «Продолжить» сразу открывает выбор режима без запроса `dismiss`. Закрытый результат сохраняется локально для конкретной попытки и гостевого профиля.
- Убраны «Нажатий в обработке», «Выбрать новую попытку» и кнопка «На главную» на экране результата.
- Новая попытка по-прежнему начинается только после явного нажатия кнопки выбранного режима.

## Проверка в браузере

Chrome, локальная версия игры, экраны 390 × 844 и 320 × 568. Тестовая оболочка добавляла 1200 мс к ответам игровых команд, не меняя их данные. Оболочка удалена перед сборкой.

| Сценарий | Результат |
|---|---|
| Забрать ранний выигрыш | Баланс 6891 → 6894; одна анимация, десять монет |
| Продолжить после выигрыша | 17,3 мс, 0 запросов |
| Перезагрузить после продолжения | Выбор режима, баланс сохранён, повторной анимации нет |
| Начать следующую платную попытку | 6894 → 6794, одно списание 100 монет, без `dismiss` и подтверждения списания |
| Забрать 102 монеты и продолжить во время анимации | Баланс 6896; переход 12,6 мс, 0 запросов |
| Дойти до финала в демонстрационном сценарии | 120 тапов, награда 2350 монет и один подарок |
| Продолжить в финале на экране 320 × 568 | Баланс 9246; переход 11 мс, 0 запросов; кнопки помещаются на экране |
| Серия из четырёх тапов в сценарии с белкой | Четыре тапа учтены, белка на четвёртом; подписи об обработке нет |
| Завершить проигрыш и продолжить | Баланс 9246 без начисления; новой анимации нет; переход 21,5 мс, 0 запросов |

Визуально проверены полёт к кошельку и итоговый экран. Слой анимации имеет `pointer-events: none`; нажатие «Продолжить» во время полёта успешно. Замеры описывают обновление интерфейса в тестовом браузере, а не скорость сети на любом устройстве. Начало попытки и начисление денег остаются серверными операциями.

## Автоматические проверки

- Проверка типов TypeScript и production-сборка.
- 39 тестов механики/API, включая очередь из 120 быстрых тапов, повторные запросы, однократные списания и начисления, ежедневную бесплатную попытку.
- Новые проверки: локальное продолжение не меняет финансовое состояние; следующая попытка стартует без закрывающего запроса; перелёт появляется только при новом подтверждённом выигрыше; проигрыш, пополнение, повтор ответа и загрузка страницы не создают ложного перелёта.
- Полный набор `node --test tests/*.test.mjs`: 44 теста пройдены, 0 ошибок, включая пять проверок компонентов и собранного приложения.

Режим уменьшенного движения предусмотрен: вместо полёта кратко подсвечивается кошелёк. Реальный телефон и системная настройка уменьшенного движения в этой итерации вручную не проверялись.
