# Bristol — игровой аудит 4 сентября 2026

Проверяется гостевая версия игры «Собери пакет», экономика `new_balance_120_draft_v1` из предоставленного Excel. Монеты и подарки демонстрационные.

## Найдено и исправлено

| Проблема | Исправление |
| --- | --- |
| Игра требовала ChatGPT на уровне хостинга и API | Публичный доступ и автоматически создаваемый гостевой профиль с HttpOnly cookie; игровой баланс остаётся на сервере |
| Пакет, монета, белка и изображения друзей имели тёмные прямоугольники | Восстановлены прозрачные изображения непосредственно из Figma, без перерисовки персонажей |
| `crypto.randomUUID` блокировал запуск в браузере без secure context | Совместимый генератор ключей команд через `crypto.getRandomValues` |
| Переключение вкладки моментально завершало игру | Пауза до 5 минут, восстановление той же попытки и понятное объяснение автофиксации |
| Закрытый результат возвращался после перезагрузки | Закрытие результата сохраняется на сервере |
| Непонятно, сколько будет на следующем тапе и насколько он рискован | Показываются следующая сумма и вероятность белки из исходной таблицы |
| Спасение за 50 могло подаваться как выгода даже при выигрыше 2–50 | Показано предупреждение; после спасения можно сразу забрать награду |
| Экран победы скрывал общий убыток от платы за попытку и бустера | Нейтральный заголовок при досрочном завершении; расходы и чистый итог к балансу |
| Запрос мог бесконечно оставлять управление заблокированным | Тайм-аут, сообщение о связи и повтор той же команды без двойного списания |
| Незавершённая команда могла пережить смену гостевого профиля | Привязка команды к профилю, очистка чужой неподтверждённой команды |
| Тестовый код BRISTOL переставал работать для всех после общего лимита | Демонстрационный бонус один раз для каждого гостя; настоящие приглашения сохраняют лимиты |
| Обучение заканчивалось ещё одним лишним нажатием «Играть» | Последний шаг запускает игру; повтор обучения во время игры возвращает в неё |
| Ссылка на пополнение была скрыта за дополнительным меню | При нехватке монет платный экран предлагает тестовое пополнение |
| Подсказка перекрывалась пакетом | Зарезервировано место под текст; адаптированы малые экраны и размеры кнопок |
| Кнопка X на главной ничего не делала | На главной находится доступ к коллекции подарков |
| При игре с клавиатуры фокус мог автоматически перейти на покупку бустера | Диалоги белки и результата получают фокус целиком, без автоматического выбора платного действия |

## Анализ экономики

Таблица выплат и вероятностей сохранена без изменения. Выплата — общее значение на текущем тапе. Платная попытка стоит 100, бустер — 50, начальный баланс — 1 000.

Аналитический расчёт последовательных независимых выпадений по исходной таблице:

| Рубеж | Пройти без спасения | Пройти с максимум одним спасением |
| --- | ---: | ---: |
| 20 тапов | 58,70% | 90,39% |
| 60 тапов | 18,65% | 50,42% |
| 100 тапов | 4,03% | 17,19% |
| 120 тапов | 0,666% | 4,105% |

Вторая колонка учитывает не более одной белки и предполагает, что игрок всегда оплачивает доступное спасение, имеет монеты и не забирает выигрыш раньше. Это вероятность дойти, а не обещание доходности. Финальный подарок редкий; досрочная фиксация — полноценный игровой выбор. Демонстрационные сценарии отдельно маркированы и не меняют обычную игру.
