# Бристоль — Собери пакет

[Открыть игру без регистрации](https://bristol-soberi-paket.meowed.chatgpt.site)

Рабочая демонстрация мобильной игры по БФТ, таблице баланса и макетам Figma. Входит: обучение, 120 тапов, случайная белка, один бустер, фиксация выигрыша, ежедневная бесплатная попытка, платные попытки, приглашение друга, история операций, тестовый подарок, фоновая аркадная музыка, звуковые эффекты, анимации, вибрация и демонстрационные сценарии.

## Запуск и проверка

- `npm run install:ci` — установить зависимости.
- `npm run dev` — локальная разработка с эмуляцией Cloudflare.
- `npm run build` — собрать сервер и клиент.
- `npm test` — сборка и автоматические проверки.
- `node --test tests/game.test.mjs` — игровые сценарии и API с настоящей SQLite через адаптер D1.
- `npx tsc --noEmit --incremental false` — проверка типов.
- `npm run db:generate` — сгенерировать миграцию после изменения `db/schema.ts`.

Игра открывается без регистрации и входа через ChatGPT. Сервер автоматически выдаёт гостевую cookie (`HttpOnly`, `SameSite=Lax`, `Secure` на HTTPS, срок 1 год). В базе хранится хеш случайного 256-битного токена. Баланс и подарки восстанавливаются в том же браузере; другой браузер или удаление cookie создают новый гостевой профиль. Старые приватные профили не становятся общедоступными.

Для локальной разработки один раз выполните `npm run db:local`, чтобы применить начальную миграцию к эмулятору D1. Команда предназначена для пустой локальной базы; production D1 управляется Sites.

## Архитектура

`app/game.tsx` — интерфейс и команды, `lib/game/engine.ts` — машина состояний, `lib/game/economy.json` — 120 строк баланса, `app/api/game/route.ts` — гостевые сессии и транзакции D1.

`lib/game/tap-plan.ts` резервирует неизменяемые случайные исходы при запуске попытки. Клиент получает этот план и показывает результат на физическом тапе, включая появление белки, без ожидания сети. `lib/game/tap-queue.ts` отправляет нажатия по порядку пакетами до 20 и останавливает при первой белке или финале. Позднее подтверждение не повторяет анимацию. Сервер применяет тот же план и остаётся единственным источником списаний, начислений и подарков. «Забрать» и спасение ждут подтверждения принятых тапов.

**Ограничение демонстрации:** будущие исходы доступны через инструменты разработчика. Такой протокол нельзя использовать для реальных денежных или лояльностных призов: перед боевой интеграцией потребуется отдельный защищённый протокол. Он выбран здесь для немедленного отклика гостевой игры с тестовыми монетами.

Состояние и кошелёк хранятся в D1. Изменение игрока, ответ команды и событие записываются одной транзакцией. Повтор команды с тем же ключом не меняет исход и не повторяет платёж. Heartbeat не блокирует тапы. При конфликте версий клиент сверяется с сервером. При обрыве связи неподтверждённая команда доступна для явной повторной проверки; неотправленная очередь отменяется. Локально хранятся настройки, закрытый результат и неподтверждённая команда, но не баланс.

Потенциальный выигрыш — общая сумма из таблицы для текущего тапа, а не сумма всех строк. Платная попытка списывает 100 монет отдельно; её первый успешный тап даёт 102. Бустер восстанавливает тот же неудачный тап без повторного розыгрыша. Вторая белка после бустера завершает игру с нулевым выигрышем.

При переключении вкладки или перезагрузке попытка сохраняется. Можно вернуться в течение 5 минут после последней активности. Затем при следующем запросе сервер фиксирует последний подтверждённый выигрыш; `loss_pending` заканчивается без награды. Явная кнопка выхода завершает конкретную попытку сразу. Отдельного фонового планировщика в демо нет. Подарок создаётся ровно один раз при фиксации 120-го тапа. «Продолжить» мгновенно возвращает к выбору режима без запроса к серверу. Закрытый результат запоминается в этом браузере по гостевому профилю и ID попытки; сервер хранит финансовый итог. Следующий старт допускает завершённую попытку и не требует предварительной команды dismiss.

Игровая сцена показывает сумму на кону, короткую фразу, кнопки действий и компактный выбор режима. Прогноз следующего тапа, проценты и поясняющие абзацы убраны. Цена платной попытки и спасения остаётся видимой. Запросы ограничены 12 секундами; повтор использует исходный ключ операции.

## Демо-профиль

- Профиль `new_balance_120_draft_v1`, 120 тапов из предоставленного Excel.
- Начальный баланс: 1 000 тестовых монет.
- Режим выбирается компактным переключателем до старта. Кнопка «Играть за 100» сразу запускает платную попытку и списывает монеты без дополнительного подтверждения; переключение режима ничего не списывает. Бесплатная попытка доступна один раз в сутки для гостевого профиля, обновляется в 00:00 UTC (03:00 МСК); платная стоит 100 и не расходует бесплатную. Повторный явный запрос бесплатной попытки отклоняется без списания.
- Бустер: 50 монет, один раз за попытку.
- Финал: 2 350 в бесплатной / 5 000 в платной попытке.
- Код друга активируется до первой игры. Бонус — 100 каждой стороне. Лимит пригласившего — 5 в сутки / 20 всего.
- `BRISTOL` — демонстрационный код, доступный каждому гостю один раз до первой обычной игры. Он не исчерпывает общий лимит на всех посетителей. Для настоящих приглашений сохраняются лимиты 5/20.
- Кнопка «Демо · монеты» открывает пополнение и отдельные сценарии: финал на следующем тапе, белка на 4-м и 8-м тапах. Эти сценарии явно помечены и не меняют вероятности обычной игры.
- Подарок — демонстрационный код, не действующий при покупках.

## Источники и ограничения

Оригинальные изображения экспортированы из предоставленного Figma-файла: https://www.figma.com/design/8X1QVowocbd3gO7KSufe5I/ — узлы 720:5524, 720:5577, 726:4130, 720:5954, 740:5881 и вложенные компоненты. Музыка и звуковые эффекты оригинальные, синтезируются локально через Web Audio без загрузки аудиофайлов. Вход в активную игру включает музыку после первого жеста пользователя, если звук разрешён; уход в фон, выключение звука и завершение попытки останавливают фон. Настройки доступны через кнопку рядом с динамиком. Вибрация — 10 мс на тап, только в поддерживающем браузере; отсутствие API не блокирует игру.

Это демонстрация, а не интеграция с боевой программой лояльности. Реальные Bristol SSO, баланс, транзакции, каталог/выдача промокодов и внешняя аналитика не подключены. В меню демонстрации указано, что монеты и подарки только игровые. Розыгрыш билетов не входит в эту версию. Бустер 50, профиль 120 тапов и реферальные лимиты — рабочие допущения из инструкции, требующие утверждения для боевого запуска.

Для интеграции необходимо получить подтверждённые endpoint, авторизацию, ключи и ответы API по контракту; заменить тестовый кошелёк адаптером лояльности и выдачу подарков реальным поставщиком; добавить outbox, reconciliation и фоновые задачи; согласовать возвращение в приложение, таймзону, тариф бустера, лимиты и состав аналитики. Не переключать демо на реальные списания одной настройкой.

## Игровая сцена

Пакет, продукты и пол остаются объёмными моделями Three.js (`lib/game/scene-models.ts`, `components/scene-3d.tsx`). Белка использует исходную иллюстрацию Figma `/assets/thief.png`, а не трёхмерную модель. На главном экране и при отступлении показана та же белка; в поп-апе — исходная сцена захвата испуганного пакета. Варианты появления: плавный вход справа, слева или с небольшим прыжком.

Поп-ап целиком закреплён по центру viewport, с ограничением ширины и высоты. Анимируется только иллюстрация, кнопки остаются на месте. При открытом результате скрыты дублирующие счёт и пояснения за окном. На подтверждённом спасении белка отступает, пакет возвращается в центр.

WebGL использует освещение и гладкие материалы, до 45 кадров/с и DPR не выше 1,5. Если WebGL недоступен, `lib/game/software-renderer.ts` проецирует те же 3D-модели на Canvas2D с упрощённым светом и геометрией, до 24 кадров/с. В этом режиме спокойные позы не перерисовываются непрерывно. Старые изображения используются только при отказе обоих рендереров. Объекты и обработчики освобождаются при размонтировании. Скрытая вкладка приостанавливает сцену; `prefers-reduced-motion` отключает погоню и декоративные движения.

Музыка — оригинальная игровая тема в миноре с синкопированным басом, маримбой, короткими аккордами и мягкой перкуссией, 114 BPM. Напряжение добавляет акценты. Web Audio начинает звучать после жеста игрока; звук, музыка и эффекты отключаются отдельно. Музыка останавливается в фоне и по окончании попытки.

Перелёт монет, радость, конфетти и короткие реакции не блокируют кнопки. Числа от тапов ограничены восемью; повторные тапы не создают очередь анимаций. Восстановление уже проигранной попытки не повторяет кражу.

Актуальная проверка: [docs/scene-3d-test-report.md](docs/scene-3d-test-report.md). История предыдущих растровых персонажей: [docs/character-assets.md](docs/character-assets.md).

## Выкрики, продукты и поверхность

На активной попытке белка иногда обращается к игроку справа. В пузыре показан портрет из исходной иллюстрации белки. Одновременно виден только один выкрик, показ 2,4 секунды и плавное исчезновение за 280 мс, интервал не менее 10 секунд и максимум четыре на попытку. Новые выкрики появляются только на новых нажатиях; после остановки очередь сообщений не доигрывается. Счётчик сохраняется в sessionStorage при перезагрузке текущей вкладки. Выкрики не предсказывают фактический исход.

Из пакета вылетают маленькие объёмные яблоки, упаковки, банки и хлеб. Используется фиксированный пул из десяти объектов, без накопления анимаций; эффект прекращается при краже и уменьшении движения. Примерно каждый третий тап даёт лёгкий наклон в чередующиеся стороны. Физика и эффекты не меняют очередь игровых команд.

Пакет получил матовую поверхность, швы и складки, уменьшенные черты лица. Белка возвращена к исходному образу из Figma по запросу пользователя. Персонажи стоят и перемещаются по плиточному полу с контактными тенями. На главном экране видны оба героя, кошелёк уменьшен.

## Развёртывание

Приложение использует серверные маршруты, Cloudflare Workers и D1. GitHub хранит исходный код. GitHub Pages не запускает API этой игры. Для собственного развёртывания настройте D1 и примените миграции перед запуском Worker.
